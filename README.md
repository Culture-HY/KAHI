# 오늘의 파운데이션 양조절 ♡

모바일 우선 한국어 파운데이션 양조절 연습 게임입니다. 첨부된 3D 캐릭터 원본 이미지를 기본 캐릭터로 사용합니다.

## 로컬에서 실행

프로젝트 폴더에서 아래 명령으로 로컬 서버를 실행한 뒤 `http://localhost:8080`에 접속하거나, 폴더 전체를 정적 웹 호스팅에 배포하세요.

```bash
python -m http.server 8080
```

권장 배포처는 Netlify입니다. ZIP을 압축 해제한 뒤 프로젝트 폴더 전체를 배포하면 됩니다.

## 구현된 기능

- 다크서클, 잡티, 피부 결 3가지 독립 설정과 8가지 조합
- 피부 설정 저장 및 첫 설정 완료 캐릭터 공개 화면
- 리퀴드: 펌프(1~5단위 누적), 덜어내기(2~3단위), 스파출러, 퍼프 순서
- 쿠션: 퍼프 찍기(1~5단위 누적), 덜어내기(1~5단위), 얼굴 도포
- 스틱: 양 볼 도포 횟수 누적(1~4회 적정, 5회부터 감점), 브러시 블렌딩
- 제품별 피부 표현: 리퀴드/쿠션은 선택한 결점을 일부 남기고, 스틱은 모두 가림
- 분:초 타이머, 화장 완성도 70점 + 시간 점수 30점, 제품별 가중치
- 로컬 기록 저장, TOP 30 화면
- Supabase 설정 시 익명 사용자 계정, 기록 서버 저장, 공유 TOP 30 조회, 완성 이미지 업로드

## 공유 TOP 30 활성화

현재 `config.js`의 Supabase URL과 anon/public key가 비어 있으므로 지금 상태에서는 연습 기록이 현재 브라우저의 로컬 저장소에만 남습니다. 따라서 아직 실제 글로벌 랭킹이 활성화된 상태는 아닙니다.

1. Supabase 프로젝트를 생성합니다.
2. Supabase 대시보드의 Authentication 설정에서 **Anonymous Sign-ins**를 활성화합니다.
3. SQL Editor에서 `supabase/schema.sql` 전체를 실행합니다.
4. `config.js`의 값을 프로젝트 URL과 anon/public key로 바꿉니다.
5. 폴더 전체를 Netlify 등의 정적 호스팅에 배포합니다.

```js
window.APP_CONFIG = {
  supabaseUrl: "https://YOUR-PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_SUPABASE_ANON_PUBLIC_KEY"
};
```

프런트엔드에는 anon/public key만 사용하세요. **service_role 키는 절대 브라우저 코드에 넣지 마세요.**

## 점수 기준 수정

`app.js`의 `SCORE_CONFIG`에서 리퀴드/쿠션 목표량, 시간 기준, 제품별 가중치를 변경할 수 있습니다. 쿠션의 적정량은 원 요청서에 수치가 지정되어 있지 않아 초기 기준값 5단위로 설정했습니다. 서버 점수 계산도 동일하게 `supabase/schema.sql`의 RPC 함수에서 5단위를 사용하므로 변경 시 두 곳을 함께 수정하세요.

## 보안 및 랭킹 안내

기록은 브라우저에서 직접 테이블에 넣지 않고 Supabase RPC 함수가 점수를 다시 계산하도록 구성했습니다. RLS를 적용하고 service role key를 사용하지 않습니다. 다만 브라우저에서 전달되는 사용자 입력값 자체를 완벽히 위변조 방지하는 부정행위 방지 시스템까지 구현한 것은 아닙니다. 상업 캠페인 등에서 엄격한 공정성이 필요하다면 서버 측 세션 토큰과 단계별 이벤트 검증을 추가하세요.

닉네임은 TOP 30에 공개되므로 실명, 전화번호 등 개인정보를 사용하지 않도록 안내합니다.
